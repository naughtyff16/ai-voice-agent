## 1. Scope

In scope: every current entry point declared by 6A–6M — public REST (`/api/v1`), internal REST (`/api/internal/v1`), provider callbacks (including bare-path provider callbacks) and WebSocket channels (`/ws/v1`, §6, counted separately).

Out of scope: DTO fields, error-code catalogs, authorization matrices, versioning strategy, OpenAPI/Swagger, application code, migrations. Where a column's value is not stated by the owning source, the cell reads **NOT SPECIFIED IN FROZEN SOURCE** or **NOT SPECIFIED IN ROW — per <owner ref>** (the owner's section-level default). `N/A` is used only where the attribute cannot apply (e.g. idempotency on `GET`).

## 3. Method

1. **Extraction.** The FAR route extractor was re-run over the 13 source documents (1,700 raw occurrences on this rerun vs. 1,697 retained by FAR §16.7 L2274–L2280; see AMI-F-08). Every hit is `(doc, line, method, path)`.
2. **Coverage key.** `(method, surface, semantic path)`; prefix `/api/internal/v1` or `/internal/v1` → INTERNAL, `/api/v1` → PUBLIC, bare path → PUBLIC; every `{…}` → `{param}`. This reproduces the FAR semantic dimension: **448** semantic keys.
3. **Ledger.** One row per owned entry point, built from each owner's route inventory / section headings (6C §15, 6D §28, 6E §30 section extractors; tables elsewhere). Every row key must exist in the extraction (checked) and be unique (checked).
4. **Residual accounting.** Every semantic key not covered by a row is classified either into the §9 exclusion register or as a shorthand reference resolved to an existing row (§9.2). Unclassified residual must be 0 (checked).
5. **FAR reconciliation.** All 56 FAR §2.1 groups are parsed from FAR L74–L135 and mapped to index rows; owner must match (§8).
6. **Parameter canonicalization policy.** The index uses the owning document's descriptive parameter names. Literal `{id}` is kept where the owner itself declares `{id}` (6D phone-numbers; 6G companies, deals, pipelines, activities, tasks, notes, appointments, suppressions; 6J inbound-webhook-events). Consumer spellings (`{id}`, `{cc_id}`, …) are not separate routes (FAR §2.1 L71 shorthand rule; 31 multi-spelling groups).
7. **No invention.** Auth, permission, idempotency, pagination, tier, response style and readiness are copied from the owning row/section with a line reference, or marked NOT SPECIFIED.

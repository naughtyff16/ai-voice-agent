    routine                                                    | secdef | vol
    -----------------------------------------------------------+--------+-----

    search_path is pinned explicitly on all four:
      fn_is_canonical_usage_metric    search_path=pg_catalog
      fn_platform_set_quota_override  search_path=billing, organization, pg_catalog
      fn_resolve_effective_quota      search_path=billing, organization, pg_catalog

    voice.fn_assert_agent_quota_admission is a CREATE OR REPLACE of the function
    introduced by 110_5C2; its signature, SECURITY INVOKER posture and
    search_path are unchanged. 110_5C2 itself was not modified.

  Table billing.quota_overrides - constraints:

    chk_qo_expires_after_start  CHECK (expires_at IS NULL OR expires_at > effective_from)
    chk_qo_hard_limit           CHECK (hard_limit IS NULL OR hard_limit >= 0)
    chk_qo_limits_order         CHECK (soft_limit IS NULL OR hard_limit IS NULL OR soft_limit <= hard_limit)
    chk_qo_metric_canonical     CHECK (billing.fn_is_canonical_usage_metric(metric))
    chk_qo_reason_length        CHECK (length(reason) >= 10 AND length(reason) <= 2000)
    chk_qo_soft_limit           CHECK (soft_limit IS NULL OR soft_limit >= 0)
    chk_qo_unit_label_length    CHECK (length(unit_label) >= 1 AND length(unit_label) <= 100)
    pk_quota_overrides          PRIMARY KEY (id)
    + NOT NULL on id, organization_id, metric, unit_label, reason, created_by,
      effective_from, created_at

    hard_limit is deliberately NULLABLE: a NULL effective hard_limit is the
    representation of "unlimited / overage allowed", and the directive forbids
    imposing a NOT NULL or integer-only rule on it. soft_limit <= hard_limit is
    enforced only when both are present.

  Table billing.quota_overrides - indexes:

    pk_quota_overrides         UNIQUE btree (id)
    uq_qo_org_metric_current   UNIQUE btree (organization_id, metric)
                               WHERE superseded_at IS NULL
    idx_qo_org_metric_history  btree (organization_id, metric, effective_from DESC)

    uq_qo_org_metric_current is the structural guarantee that at most ONE
    non-superseded override can exist per (organization, metric). It is a
    partial unique index, so superseded history rows are unconstrained and the
    full override history is retained.

  billing.quota_configs is NOT overloaded by 111: no column was added, dropped
  or repurposed there. 111 only attaches four LEGACY documentation comments to
  the pre-existing override columns (see FAR_111_02 section 6).
